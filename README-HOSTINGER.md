# OP Productions Hostinger Deployment

This folder is ready for Hostinger **Deploy Your Node.js Web App**.

## Settings

- Framework: `Express.js`
- Entry file: `app.js`
- Start command: `npm start`
- Node version: `18` or newer
- Port: `3000` or Hostinger's assigned `PORT` environment variable

## Upload Or Git Import

Upload/import the whole folder, including:

- `package.json`
- `package-lock.json`
- `app.js`
- `server.js`
- `index.html`
- `about.html`
- `blogs.html`
- `css/`
- `js/`
- `images/`
- `home/`
- `contact/`
- `episode-s/`

The app serves clean routes such as `/`, `/about`, `/blogs`, and redirects `/home` plus `/home/home` back to `/`.
